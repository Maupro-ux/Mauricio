# sitio-ux-301

## Tema: Mundial FIFA 2026

## Descripción

Sitio web estático desarrollado como proyecto académico para la materia de
**Experiencia de Usuario (UX)** en la carrera de **Ingeniería en Tecnologías
de la Información e Innovación Digital**.

El sitio presenta información general sobre la Copa Mundial de la FIFA 2026,
incluyendo una introducción al torneo, historia y países anfitriones, galería
de imágenes, artículos de noticias y un formulario de contacto. Todo el
contenido está estructurado con etiquetas semánticas de HTML5 y navegación
mediante listas desordenadas.

---

## Páginas del Sitio

| Archivo          | Descripción                                        |
|------------------|----------------------------------------------------|
| `index.html`     | Página de inicio y presentación general del torneo |
| `about.html`     | Historia, países anfitriones y formato del torneo  |
| `galeria.html`   | Galería de imágenes representativas                |
| `blog.html`      | Artículos y noticias del Mundial 2026              |
| `contacto.html`  | Formulario de contacto                             |

---

## Tecnologías Utilizadas

- **HTML5** – Estructura semántica del sitio web (`header`, `nav`, `main`, `section`, `footer`, `article`)
- **CSS3** – Estilos y presentación visual (archivo externo: `css/styles.css`)

## Imágenes Requeridas

Antes de abrir el sitio en un navegador, coloca las siguientes imágenes
en la carpeta `img/`:

| Archivo          | Descripción sugerida                                      |
|------------------|-----------------------------------------------------------|
| `hero.jpg`       | Logo oficial o imagen representativa del Mundial 2026     |
| `estadio.jpg`    | Fotografía de un estadio sede (ej. Estadio Azteca)        |
| `seleccion.jpg`  | Fotografía de selecciones o jugadores participantes       |

---

## Instrucciones de Uso

1. Clona o descarga el repositorio en tu equipo.
2. Agrega las imágenes requeridas en la carpeta `img/`.
3. Personaliza el archivo `css/styles.css` con los estilos deseados.
4. Abre `index.html` en cualquier navegador web moderno.

No se requiere servidor web; el sitio funciona directamente desde el
sistema de archivos local.
